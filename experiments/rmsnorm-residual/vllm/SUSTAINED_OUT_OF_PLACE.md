# Remove input restoration when the caller preserves both BF16 inputs

In the eight-stream test at 128 × 4,096, staging restoration separately counted roughly half of the coordinated CUDA interval in copying for the Triton kernels. The next experiment tests a single output-equivalent kernel that reads immutable activation and residual tensors directly and writes the normalized activation and updated residual to disjoint output buffers. This contract represents callers that need both original inputs after the operation. [Copy and operator evidence](COPY_SPLIT_REPORT.md)

Retain the ordered 16-warp FP32 reduction and the two BF16 rounding steps. Compare the out-of-place implementation with the released vLLM, frozen 8-warp and frozen 16-warp in-place operators, each preceded by the same restoration into writable buffers. Every backend must produce both outputs in the same designated addresses and preserve both source tensors and the weight. Use the same eight CUDA streams, 32 disjoint pairs per stream, and pinned extension and hardware.

Use seed 145 for a separate accuracy checkpoint. Poison the writable outputs before the graph replay and compare both outputs bitwise with vLLM after verifying every source digest. Include the signed-zero and weight-rounding fixtures. Recheck both outputs at the end of each measured block. Start independent timing on seeds 146–148 after qualification passes.

Use 32 graph replays per stream in each burst and four balanced rounds so that all four backends occupy each scheduling position once per seed. Each period has at least one second of warm-up and four seconds of completed measurement. Accept the candidate if its median normalized-row throughput is at least 5% above each of the three input-preserving baselines in every seed. Preserve original event times, completed work, input fingerprints, loaded binary hashes, and NVML activity, memory and power samples.
